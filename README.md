# Sonder Barbershop website concept

Independent website demo by David Garcia for Sonder Barbershop in Pilsen, Chicago. This is a pitch concept, not Sonder's official website.

**Live demo:** https://davidgarcia355.github.io/sonder-barbershop-website/

The page uses Sonder's publicly available shop details and brand assets, with Erick Rios's portrait and portfolio provided for this concept. It features a one-page layout, animated barber-pole menu, barber profiles, Google-review excerpts, portfolio interactions, and an interactive booking prototype.

**Booking is a prototype.** Dates and times are samples. The form does not check the shop's calendar, reserve a chair, send an appointment, or take payment. To book a real appointment, use [Sonder's current booking page](https://www.sonderbarbershopchicago.com/sonder_barber-shop_book_appointment) or call the shop.

Review excerpts are a curated snapshot from a user-provided Google review capture, not a live Google feed. The full Google reviews are linked from the page. Shop details should be rechecked with Sonder before any official launch.
